# Play Store Submission Pack

Prepared files:

- play-store-listing.md: App name, descriptions, category, release notes and keywords.
- privacy-policy.md: Privacy policy draft to publish at https://tailorahub.com/privacy.
- reviewer-access.md: Demo login instructions for Google reviewers.
- data-safety-draft.md: Data Safety questionnaire guidance.
- asset-checklist.md: Icons, feature graphic and screenshot checklist.
- release-notes.md: Short release notes for the release form.

Immediate manual task in Google Play Console:

1. Finish contact phone verification.
2. Wait for identity verification if Google is still reviewing documents.
3. Create the app listing using play-store-listing.md.
4. Publish the privacy policy page and set the URL to https://tailorahub.com/privacy.
5. Upload screenshots and a 1024 x 500 feature graphic.
6. Add reviewer demo credentials from reviewer-access.md.
7. Fill Data Safety using data-safety-draft.md.
8. Upload the AAB from pwa/android-twa/app-release-bundle.aab.
