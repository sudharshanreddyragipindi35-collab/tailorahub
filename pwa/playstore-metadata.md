# TailoraHub Play Store Metadata Draft

## App Name

TailoraHub

## Short Description

Book verified tailors, track stitching orders and manage tailor services.

## Full Description

TailoraHub is a tailoring marketplace built for customers, tailors and platform administrators. Customers can discover verified tailors, view services and pricing, book stitching work, share measurement locations, track orders, complete payments and submit feedback after delivery.

Tailors can manage availability, services, offers, media, followers, bookings, order progress, wallet earnings and withdrawal requests. Admins can approve tailors, manage orders, verify payments, handle disputes, view finance settings and operate the platform securely.
